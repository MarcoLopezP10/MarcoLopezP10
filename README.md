## 📌 Featured Projects

### 🏥 [Aviso Vital — Accessible Medical Reminder App](https://github.com/MarcoLopezP10/aviso-vital)
> *Final Degree Project · Dart/Flutter · Supabase · Vercel*

A full-stack **medical reminder web app** designed for elderly patients struggling with medication adherence. Features 4 integrated modules (medications, appointments, contacts, monitoring), accessibility-first UI (large fonts, high contrast, voice alerts), and a real-time **remote monitoring dashboard** for family members and caregivers. Usability-tested with 5+ participants.

🔗 **[Live Demo → aviso-vital.vercel.app](https://aviso-vital.vercel.app)**

---

### ⚡ [Swarm Engine — PSO Parallel Optimization Framework](https://github.com/MarcoLopezP10/swarm-engine)
> *Parallel Programming · Python · Honors (Matrícula de Honor)*

A modular **Particle Swarm Optimization** framework built from scratch — no external PSO libraries. Implements and benchmarks **4 parallelism strategies** (sequential, threading, multiprocessing, asyncio) across 1,200+ lines of documented code with 3 abstract interfaces for transparent strategy-swapping. Benchmarked on Sphere, Ackley, Rosenbrock & Rastrigin functions, plus a real-world EDL use case.
